# Apollo - Website Template

Apollo is a Hugo website template & theme that allows you to start developing right away. Apollo comes built in with support for TailwindCSS, and NetlifyCMS, along with a Netlify config file that allows for instant deploys. 

## Requirements
- Latest version of Hugo
- Latest versions of Node & npm

## Steps

To use Apollo, simply:

1. Clone this repository into whatever folder you will be working in.
2. Create a new GitHub repository for your project. Set a second remote for that repository.
3. Run NPM install to install TailwindCSS and any other included packages.
4. Change the theme name and other misc. data to your own values.
5. Deploy to Netlify.

## After building...

To get your CSS styles to work via Tailwind, you need to run the following command: ` npm run build-tw `. To have continious updating, run `npm run build-tw-w`.
